## Resumen

- **Consigna:** diseñar, programar y simular en RoboDK una celda robotizada que cumpla una tarea concreta.
- **Movimientos:** MoveJ, MoveL y MoveC. Python no se usa para mover el robot; solo para sensores adicionales.
- **Complejidad mínima:** frames y TCP propios, programa principal con subprogramas, una cinta, un segundo
  robot o variantes, y un ciclo repetible sin colisiones ni puntos fuera de alcance.
- **Entrega:** archivo de la estación e informe técnico de 8 páginas como máximo.

La lectura detallada de cada requisito y dónde se cumple está en
[requisitos y trazabilidad](../b_investigacion/conceptos/00_requisitos_y_trazabilidad.md).
